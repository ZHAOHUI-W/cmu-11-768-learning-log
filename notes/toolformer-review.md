## 1. 数据生成与符号

主线正确：少量人工示范与工具定义 → 候选调用采样 → 实际执行 → 根据后续预测损失筛选 → 构造工具增强语料 → 微调。

自监督体现在利用原始文本的后续 token 及模型损失自动产生筛选信号，不需要逐条人工标注调用是否有用；仍需要人定义工具、接口及少量示范。

调用的二元组是 c = (a_c, i_c)，分别为 API 名称和输入参数，r 是执行后得到的结果。e(c, r) 是包含调用与结果的序列化文本，并非仅有工具名称。

    <API>Calculator(2+3) → 5</API>

采样步骤中的符号：i 为插入调用的位置；k 为候选位置数上限；m 为每个位置最多采样的调用数。先要求 p_i > τ_s，位置过多时保留概率最高的 k 个。多次采样是生成候选调用，可产生不同参数或内容，不是在枚举任意接口格式。

## 2. 筛选方向与距离权重

    L+ = L_i(e(c_i, r_i))
    L− = min(L_i(ε), L_i(e(c_i, ε)))
    保留条件：L− − L+ ≥ τ_f

L− 是两个对照损失的较小值：完全不调用，以及只有调用文本而无返回结果。完整调用与结果必须比这两个对照都至少降低 τ_f 的损失；这样可排除仅靠调用文本本身就改善预测的情况。保留的是通过筛选的调用，用于构造增强样本，并非只保留一个 token，也不等于只选损失下降最大的候选。

损失是后续 token 的加权交叉熵，形式为 L_i(z) = Σ_{j=i}^n w_{j−i} ℓ_j(z)，其中 ℓ_j 为第 j 个 token 的负对数概率。距离 d = j−i 越大，论文设置的权重越小：未归一化权重为 max(0, 1−0.2d)，之后归一化。不是要求远处 token 的预测误差本身更小，而是更关注调用附近的收益。k 在此处不是距离或当前位置。

## 3. 微调与推理

“SFT”的方向基本正确；更精确地说，论文在自动构造的工具增强语料上使用标准自回归语言模型目标做微调，不是 RL。自监督描述监督信号的来源，与训练目标使用交叉熵不矛盾。

推理生成到调用中的箭头标记时暂停，由外部执行流程调用工具，得到真实结果，再追加结果和结束标记，继续模型生成。模型生成调用，外部工具实现产生结果。

## 4. 四组实验对照

| 模型 | 设置 |
| --- | --- |
| GPT-J | 未经此次微调的原始模型 |
| GPT-J + CC | 在不含 API 调用的普通 CCNet 子集 C 上微调 |
| Toolformer | 在工具增强数据 C* 上微调，推理时可调用工具 |
| Toolformer (disabled) | 与 Toolformer 相同权重，推理时禁止发起工具调用 |

GPT-J 与 GPT-J + CC 帮助判断额外语料微调的影响；Toolformer 与 disabled 帮助判断推理时工具访问的收益；disabled 与 GPT-J + CC 帮助观察工具增强训练本身在禁用工具时的影响。只比较 Toolformer 与原始 GPT-J，无法区分额外微调与推理工具使用等因素。

## 5. 能力边界

降低局部文本预测损失不保证长程任务成功，也不直接优化工具调用成本。论文第 5 节还展示了直觉上不相关的调用仍降低困惑度的例子。

我指出的链式调用限制与论文第 7 节一致：该方法对各工具独立生成调用，微调数据中没有把先前工具结果用于后续调用的链式示范，因此不能有效支持这类使用方式。论文也指出缺乏交互式搜索与查询调整能力；这些是本文方法和训练设置的局限。

## 公式释疑与讲解收尾

之后进一步询问 L_i+、L_i− 的具体公式、为什么使用 w_d，以及归一化分母为何为 3。

反馈：在固定模型下预测同样的原文后续 token，只改变提供的辅助前缀 z。损失不计算调用与工具结果本身；L_i− 对两个完整加权损失取较小值。筛选时辅助信息前置于原文，微调样本阶段才在位置 i 插入调用。

w_d 是人为设定的距离权重，强调调用附近的即时收益。未归一化权重依次为 1、0.8、0.6、0.4、0.2，之后为零，总和为 3；归一化后为 1/3、4/15、1/5、2/15、1/15。距离增大使权重下降，不要求预测误差本身随距离下降。

根据“继续”的请求，用讲解补齐前面的算例与对照：

- L− = min(2.0, 1.0) = 1.0；改善为 1.0 − 0.9 = 0.1，小于阈值 0.2，所以不保留。
- 若只比较无调用，得到 2.0 − 0.9 = 1.1，会把调用文本本身带来的收益误当作返回结果的增量收益。
- GPT-J + CC 用于判断额外普通语料微调的影响。只比较原始 GPT-J 与 Toolformer，会混合额外微调、工具增强数据与推理工具访问等因素。
